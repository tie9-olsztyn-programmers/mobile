## Connecting the Modules

### 💡 Metaphorical Tip: "Houston, We Have a Router"
Individual spacecraft cabins (`ui/screens`) cannot talk directly to each other.
The Launchpad cabin has no idea that the Orbit cabin even exists.

**`VenusMissionControl`** is Houston Ground Control. It holds the master switchboard (`currentPhase`) and
the mission clipboard (`astronautName`). When the Launchpad cabin sends a signal up the wire saying
*"Commander Bob is ready to launch!"*, Houston writes "Bob" on the clipboard and flips the master switch
from `LAUNCHPAD` to `ORBIT_TRANSIT`. Instantly, the Launchpad cabin vanishes, and the Orbit cabin appears
on screen with "Bob" already displayed on its monitor.

### ⚙️ Technical Tip: "State Hoisting"
Notice that `astronautName` is stored here inside `VenusMissionControl`, even though the text field where
the user types it is inside `LaunchpadScreen`. Moving state up to a common parent so multiple screens can read and modify it is called **State Hoisting**.
* If `astronautName` stayed inside `LaunchpadScreen`, it would be destroyed the moment `LaunchpadScreen` disappeared from the screen!

:::tip Intercepting the System Back Button (`BackHandler`)
Because we are not using an external navigation library, Android does not know our screen history (backstack). If the user is on Venus and presses the physical system **Back** button on their phone, Android's default behavior is to immediately close the entire app!

To prevent our astronauts from being sucked into the void, we use the **`BackHandler`** Composable inside `ORBIT_TRANSIT` and `VENUS_SURFACE`. It intercepts the physical Back button press and manually rewinds our `currentPhase` variable to the previous stage. *(Notice we do **not** put a `BackHandler` on `LAUNCHPAD`—on the first screen, pressing Back should exit the app normally!)*
:::

## 💻 Implementation: `VenusMissionControl.kt`

Inside your `navigation` package, create a new Kotlin file named **`VenusMissionControl.kt`**:

```kotlin

import androidx.activity.compose.BackHandler
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue


@Composable
fun VenusMissionControl() {
    // 1. Mission Control State (Current Phase & Shared Payload Data)
    var currentPhase by remember { mutableStateOf(MissionPhase.LAUNCHPAD) }
    var astronautName by remember { mutableStateOf("") }

    // 2. The Router (Switching screens based on state)
    when (currentPhase) {
        MissionPhase.LAUNCHPAD -> {
            LaunchpadScreen(
                onLaunchClick = { enteredName ->
                    astronautName = enteredName // Saving the payload
                    currentPhase = MissionPhase.ORBIT_TRANSIT // Changing the phase
                }
            )
        }
        MissionPhase.ORBIT_TRANSIT -> {
            // Intercepting the physical system Back button
            BackHandler {
                currentPhase = MissionPhase.LAUNCHPAD
            }
            OrbitScreen(
                commander = astronautName,
                onLandClick = {
                    currentPhase = MissionPhase.VENUS_SURFACE
                },
                onAbortClick = {
                    currentPhase = MissionPhase.LAUNCHPAD
                }
            )
        }
        MissionPhase.VENUS_SURFACE -> {
            BackHandler {
                currentPhase = MissionPhase.ORBIT_TRANSIT
            }
            VenusSurfaceScreen(
                commander = astronautName,
                onReturnHomeClick = {
                    astronautName = "" // Resetting payload
                    currentPhase = MissionPhase.LAUNCHPAD
                }
            )
        }
    }
}
```
